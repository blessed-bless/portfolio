## Problem

One loop from brief to archive: roles PM → Architect → Engineer → Reviewer → DevOps, a shared blackboard, LLMs via OpenRouter or subscription runners (Codex / Claude / Cursor), metrics, and a zip ship bundle. Locally it runs in demo mode without keys.

## Approach

FastAPI orchestrates turns. React shows the board. Each role writes artifacts to the blackboard; DevOps packs the prod zip when Reviewer clears the gate.
