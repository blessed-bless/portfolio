## Problem

Learn that a client’s site is down before the client messages you. No separate browser dashboard for every check: open Telegram — see status, chart, and incidents.

## Solution

- **Bot + Mini App.** Up to 10 sites per user, intervals 1 / 5 / 15 minutes.
- **Uptime 24h / 7d / 30d**, SVG response-time chart, incident feed.
- **Alerts** for downtime, slow responses, and SSL expiry.
- **Public status page** `/s/<slug>` — domain, status, availability, and incident types without login.
- **Weekly report** with p95 per site.
- **`initData` signature checks**, SSRF protection on redirect chains and resolved addresses.

## Stack

Node.js 24, SQLite (WAL), Telegram Bot API / Mini App, Docker. No npm dependencies in the service — one process runs HTTP, the scheduler, and the bot.
