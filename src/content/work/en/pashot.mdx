## Problem

The cafe already had a basic site. I rebuilt the page by hand, with my own components: menu, photos, map, contacts. It is one scroll, not a separate catalog.

## Solution

- **Menu.** Tabs for the main menu and drinks, then a price filter inside each.
- **Gallery.** A photo grid and a lightbox.
- **Map and contacts.** The address, hours, and phone.
- **Phone first.** Layout starts at a narrow width. Scroll is the browser's own, with no scroll-jacking.
- **Logo.** Sofia Sans Condensed, the font file hosted with the page.
- **Images.** AVIF and WebP through `astro:assets`.
