## Задача

Мастеру нужен день в Telegram: визиты, перерывы, клиенты и свободные окна — без отдельной CRM и без записи в YCLIENTS. Записи администратора подтягиваются только на чтение; свои визиты и заметки мастер ведёт в «Смене».

## Решения и почему

- **Mini App + бот.** День / неделя / месяц, карточки клиентов, статусы «Пришёл / Завершён / Не пришёл», «Поделиться окнами» текстом. Бот отвечает на `/today`, `/free`, `/add`, `/find` и ведёт в нужный экран.
- **YCLIENTS только чтение.** Google Calendar iCal или официальный API — пароль YCLIENTS не хранится. Ссылка iCal сидит в SQLite `meta`, не в экспорте.
- **HMAC `initData`.** Вход через подпись Telegram, срок, allow-list id. Сессия 8 часов: Bearer в памяти + HttpOnly cookie, не `localStorage`.
- **SSRF на календарном feed.** Фиксация адреса, allow-list IP, общий таймаут и проверка сокета после коннекта.
- **`revision` против конфликтов.** Форма несёт версию данных; правка с другого устройства отклоняется.
- **Снимки и восстановление.** Ежедневные копии БД; перед restore сохраняется текущее состояние.
- **Ноль npm-зависимостей.** Node 24 stdlib + SQLite.

const secret = createHmac('sha256', 'WebAppData').update(token).digest();

if (!timingSafeEqual(Buffer.from(hash, 'hex'), expected)) {

SSRF: allow-list IP и фиксация адреса на соединении:

```js
export function pinnedFetch(url, { headers = {}, signal } = {}) {
  const host = new URL(url).hostname.replace(/^\[|\]$/g, '');
  if (isIP(host) && internalAddress(host)) return Promise.reject(blocked());
  return new Promise((resolve, reject) => {
    const req = httpsRequest(url, { headers, lookup: pinnedLookup, signal }, (res) => {
      if (internalAddress(res.socket.remoteAddress || '')) {
        req.destroy(blocked());
        return;
      }
      // …
    });
    req.on('error', reject);
    req.end();
  });
}
```

Свободные окна дня (`shared.mjs`) — те же цифры в UI и в боте:

```js
export function freeGaps(state, date, from = 0, minGap = 15) {
  const hours = workday(state, date);
  if (hours.closed) return null;
  const end = mins(hours.end), out = [];
  let scanAt = Math.max(mins(hours.start), from);
  const busy = state.records
    .filter((r) => r.date === date && isActive(r))
    .sort((a, b) => a.time.localeCompare(b.time));
  for (const r of busy) {
    const start = Math.min(mins(r.time), end);
    if (start - scanAt >= minGap) out.push([scanAt, start]);
    scanAt = Math.max(scanAt, mins(r.time) + r.duration);
  }
  if (end - scanAt >= minGap) out.push([scanAt, end]);
  return out;
}
```
