## Задача

Нужен один контур от брифа до архива: роли PM → Architect → Engineer → Reviewer → DevOps, общий blackboard, LLM через OpenRouter или subscription runners (Codex / Claude / Cursor), метрики и zip ship bundle. Локально — demo mode без ключей.

## Решение и архитектура

React UI ходит в FastAPI. Orchestrator гоняет pipeline ролей, пишет в SQLite и файлы проекта, собирает zip. LLM и runners — внешние процессы / HTTP.

## Инженерные решения

**Blackboard между ролями.** После каждого агента payload валидируется, кладётся в blackboard и материализуется в файлы артефактов.

```python
# backend/app/orchestrator.py
raw = await self._run_role(mission, role, board)
payload = coerce_role_payload(role.value, normalize_payload(role.value, raw))
issues = validate_agent_payload(role.value, payload)
if mission_id in self._cancel_requested:
    raise asyncio.CancelledError()
ingest_agent_payload(board, role.value, payload)
mission.blackboard = board.model_dump(mode="json")
artifacts = self._materialize_files(mission, role, payload)
```

**Review loop.** Если reviewer не approved и есть `required_fixes`, при `review_round < max_review_rounds` — повтор engineer.

```python
# backend/app/orchestrator.py
if role == AgentRole.reviewer:
    approved = bool(payload.get("approved", True))
    fixes = payload.get("required_fixes") or []
    if (
        not approved
        and fixes
        and mission.review_round < self.settings.max_review_rounds
    ):
        mission.review_round += 1
        self._persist(mission)
```

**Чистый env для subscription runners.** Перед запуском codex/claude/cursor вычищаю metered API keys, чтобы runner оставался на подписке.

```python
# backend/app/runners/process.py
# Strip metered API keys from the env so subscription runners stay on-plan.
STRIP_ENV = {
    "OPENAI_API_KEY",
    "CODEX_API_KEY",
    "ANTHROPIC_API_KEY",
    "ANTHROPIC_AUTH_TOKEN",
    "CLAUDE_API_KEY",
    "CURSOR_API_KEY",
}

def clean_env(extra: dict[str, str] | None = None) -> dict[str, str]:
    env = dict(os.environ)
    for key in STRIP_ENV:
        env.pop(key, None)
```
