## Задача

Один стек от хита на лендинге до менеджера: диалог `/api/chat`, Telegram-бот с квалификацией, mini-CRM (фильтры, заметки, timeline, soft-delete, CSV) и исходящие webhook / notify без потери при падении процесса.

## Решение и архитектура

Landing и бот пишут в FastAPI. Данные в SQLite. Outbox копит jobs; отдельный worker шлёт webhook и Telegram менеджеру. HTML CRM поверх того же API.

## Инженерные решения

**Dedupe по телефону.** Нормализованный номер ищет существующий лид; поля дополняются, пишется activity `dedupe_merge`, дубликат не создаётся.

```python
# src/aifunnel/services/leads.py
if data["phone_normalized"]:
    existing = await find_by_phone(session, data["phone_normalized"], include_deleted=False)
    if existing:
        # Dedupe: enrich the existing lead instead of inserting a duplicate
        merged = False
        for key in (
            "name",
            "email",
            "need",
            "budget_note",
            "telegram_id",
            "telegram_username",
            "tags",
        ):
            val = data.get(key)
            if val and not getattr(existing, key):
                setattr(existing, key, val)
                merged = True
```

**Circuit breaker для AI.** После порога failures — OPEN, через `recovery_timeout` — HALF_OPEN; success возвращает CLOSED.

```python
# src/aifunnel/reliability/circuit_breaker.py
def allow(self) -> bool:
    if self.state == CircuitState.CLOSED:
        return True
    if self.state == CircuitState.OPEN:
        if time.monotonic() - self.opened_at >= self.recovery_timeout:
            self.state = CircuitState.HALF_OPEN
            return True
        return False
    return True
```

**Outbox worker.** Цикл claim → process; ошибка — `mark_failed` с retry, пауза 2 с между тиками.

```python
# src/aifunnel/worker/main.py
while not _stop.is_set():
    async with SessionLocal() as session:
        jobs = await outbox.claim_pending(session, limit=25)
        for job in jobs:
            try:
                await outbox.process_job(session, job)
            except Exception as exc:
                await outbox.mark_failed(session, job, str(exc), retry=True)
    try:
        await asyncio.wait_for(_stop.wait(), timeout=2.0)
    except TimeoutError:
        continue
```

## Что бы улучшил дальше

Вынести claim outbox на `FOR UPDATE SKIP LOCKED` под Postgres, если уйду от SQLite по умолчанию. Сейчас Redis опционален только для общего rate-limit — для нескольких инстансов API это стоит сделать обязательным в prod-профиле.
